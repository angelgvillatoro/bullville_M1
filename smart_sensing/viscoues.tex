\textbf{Overall Vision}

Develop and experimentally validate a real-time data assimilation framework capable of predicting separated and dynamically stalled aerodynamic flows using only surface pressure/temperature sensors.
The project culminates in a high-speed wind tunnel demonstration—directly relevant to aerospace applications such as maneuvering aircraft, aeroelastic stability, and flow control.

\section{PHASE 1 (Year 1): Foundational Development + Canonical Validation}

\textbf{Goals}

\begin{itemize}
    \item Build the complete data assimilation (DA) pipeline end-to-end.
    \item Validate the approach on controlled, canonical flows before moving to complex airfoil dynamics.
\end{itemize}

\textbf{Key Actions}

\begin{enumerate}
    \item Develop Minimal Viable DA Framework
    \begin{itemize}
        \item Implement fast-enough ROM + EnKF/UKF/hybrid filter.
        \item Demonstrate real-time update capability using synthetic data.
    \end{itemize}
    \item Experimental Validation on Cylinder Flow
    \begin{itemize}
        \item Use surface pressure/temperature sensors to reconstruct vortex shedding dynamics.
        \item Assess latency, robustness, noise handling.
        \item Benchmark predictions vs. reference (PIV or CFD).
    \end{itemize}
\end{enumerate}

\textbf{Deliverables}

\begin{itemize}
    \item Working DA pipeline (ROM + filter + real-time interface).
    \item Journal/Conference Paper: “Real-time estimation of vortex shedding dynamics from surface sensors using data assimilation.”
\end{itemize}

\section{PHASE 2 (Year 2): Main Contribution — Airfoil With Dynamic Stall}

\textbf{Goals}

\begin{itemize}
    \item Demonstrate robust real-time prediction of a dynamically changing aerodynamic state (stall onset, separation, reattachment, force coefficients).
    \item Produce the core results of the PhD.
\end{itemize}

\textbf{Key Actions}

\begin{enumerate}
    \item Design and Execute Dynamic Stall Experiments.
    \begin{itemize}
        \item Airfoil with controlled pitch ramps or oscillations.
        \item Distributed surface pressure/temperature sensors.
        \item Measurements of forces, possibly PIV/Schlieren for validation.
    \end{itemize}
    \item Real-Time State Estimation
    \begin{itemize}
        \item Predict:
        \begin{itemize}
            \item lift and moment in real time
            \item flow regime (attached → pre-stall → stall → reattachment)
            \item approximate separation location
        \end{itemize}
        \item  Evaluate latency vs. characteristic flow timescales.
    \end{itemize}
    \item Model Refinement
    \begin{itemize}
        \item Improve ROM structure (SPOD/DMD-based, nonlinear ROMs, hybrid ML-physics if beneficial).
        \item Enhance DA stability under strongly nonlinear transitions.
    \end{itemize}
\end{enumerate}

\textbf{Deliverables}

\begin{itemize}
    \item Core PhD dataset and results (airfoil dynamic stall).
    \item High-quality journal paper.
    \item 80–90\% of thesis chapters drafted by end of year.
\end{itemize}

\section{PHASE 3 (Year 3): Transition to High-Speed Wind Tunnel Demonstration}
\textbf{Goals}

\begin{itemize}
    \item Adapt the method for compressible/high-Re conditions.
    \item Conduct first campaigns in the high-speed tunnel using simplified conditions.
\end{itemize}

\textbf{Key Actions}

\begin{enumerate}
    \item Method Adaptation
    \begin{itemize}
        \item Incorporate compressibility effects into the ROM, if necessary.
        \item Sensor calibration for high-speed environment.
        \item Robustness testing under increased noise and harsh conditions.
    \end{itemize}
    \item Experimental Campaign 1 in High-Speed Tunnel
    \begin{itemize}
        \item Reproduce a simplified separated flow configuration (steady or mildly dynamic).
        \item Validate real-time state estimation with surface sensors only.
    \end{itemize}
\end{enumerate}


\textbf{Deliverables}
\begin{itemize}
    \item High-impact journal paper (AIAA Journal / Journal of Fluids Engineering).
    \item Proof-of-concept demonstration in relevant aerospace conditions.
\end{itemize}

\section{PHASE 4 (Year 4): Final Demonstration + High-Speed Dynamic Stall / Buffet}
\textbf{Goals}

\begin{itemize}
    \item Execute an ambitious high-speed experiment showcasing the full capabilities of the method.
    \item Deliver the “flagship" result connecting DA + real-time + separated compressible flow.
\end{itemize}

\textbf{Key Actions}

\begin{enumerate}
    \item Full-Scale Demonstration
    \begin{itemize}
        \item Airfoil with dynamic stall or moderate transonic buffet.
        \item Real-time prediction of aerodynamic forces and flow regime transitions.
        \item Demonstrate applicability to aerospace-relevant unsteady phenomena.
    \end{itemize}
    \item Final Synthesis
    \begin{itemize}
        \item Integrate all components into a generalizable DA framework.
        \item Produce final thesis and final set of publications.
    \end{itemize}
\end{enumerate}

\textbf{Deliverables}

\begin{itemize}
    \item Final PhD thesis.
    \item “Capstone” publication: “Real-time aerodynamic state estimation in high-speed separated flows using surface sensors and data assimilation.”
    \item Dataset + software framework for future research.
\end{itemize}

\section{Expected Impact}
\subsection*{Scientific}

\begin{itemize}
    \item Advances experimental data assimilation for highly nonlinear, unsteady aerodynamic flows.
    \item Provides a framework for real-time flow state reconstruction using minimal sensing.
\end{itemize}

\subsection*{Technological / Aerospace}

Enables applications in:

\begin{itemize}
    \item maneuver load prediction
    \item stall/buffet detection
    \item aeroelastic monitoring
    \item closed-loop flow control.
\end{itemize}

\subsection*{Strategic}

Establishes the group as a leader in real-time experimental DA for aerodynamic systems.
