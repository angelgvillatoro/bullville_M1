
\section*{Weekly Checklist}
\subsection*{General Rules}
\begin{itemize}
\item Produce a measurable result every week.
\item Limit theory study to $<10\%$ of weekly hours.
\item Test pipeline components in isolation and in combination.
\end{itemize}

\subsection*{Weekly Checklist Items}
\begin{itemize}
\item Week 1: Define pipeline modules and interfaces.
\item Week 2: Implement initial ROM with synthetic data.
\item Week 3: Connect DA (UKF/EnKF) to ROM.
\item Week 4: Produce first end-to-end synthetic test.
\item Week 5: Implement SPOD/DMD ROM.
\item Week 6: Add nonlinear ROM or closure model.
\item Week 7: Noise and robustness tests.
\item Week 8: Latency optimization.
\item Week 9: Build cylinder setup.
\item Week 10: Run first experimental dataset.
\item Week 11: Adapt pipeline to real data.
\item Week 12: Real-time DA on cylinder.
\item Week 13: Prepare airfoil setup.
\item Week 14: Static tests on airfoil.
\item Week 15: ROM on airfoil data.
\item Week 16: Light unsteady test.
\item Week 17--18: Stability refinement and documentation.
\end{itemize}
